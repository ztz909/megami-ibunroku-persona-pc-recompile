# Changelog

## 1.0.0 - first release

- Megami Ibunroku Persona (SLPS-00500) recompiled to a native Windows exe with psxrecomp, from the disc patched
  with Redeted's English translation + quality-of-life patch (Persona-TL-QoL).
- First start: pick your disc image; the original Japanese disc is patched automatically into a copy
  (Redeted's patch is included), the choice is remembered.
- Runs on the bundled OpenBIOS: no PlayStation BIOS needed. No extra runtimes needed.
- Options menu (F10): screen mode, resolution, smooth picture, texture filtering, less wobble (geometry
  correction), screen colour, scanlines, volume, skip movies; keyboard and controller rebinding, stick deadzone.
- Controllers work out of the box (keyboard and controller at the same time); menus work with a controller.
- Debug menu (F9): warp list with 268 named places, warp by hand, back to title, the game's own battle cheats.
- Save states (F7), fullscreen (Alt+Enter), volume (keypad +/-).
