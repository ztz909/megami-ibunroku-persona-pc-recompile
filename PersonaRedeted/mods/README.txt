PersonaRedeted/mods - C code compiled into the patched-disc exe (route A)
=========================================================================

debug_menu.c   F9 debug menu (warp list, back to title, warp by hand, battle
               cheats). Details: research/DEBUG_MENU.md.
options_menu.c F10 options menu: DISPLAY & SOUND (screen mode, resolution,
               picture options, volume, skip movies) and CONTROLS (keyboard
               and controller rebinding, stick deadzone). Saves to
               build/settings.toml, persona_options.txt, keybinds.ini and
               input.ini.
menu_draw.h    drawing shared by both menus (640x480 panel, 8x8 font).
warp_points.h  named arrival points for the debug menu's WARP LIST.
               Generated by tools/warp_points.py (with
               research/WARP_POINTS.md); do not edit.
persona_mod.h  register names and memory helpers (copy of
               PersonaRecomp/mods/persona_mod.h).

Both menus need the host menu hook, controller input and host settings services that
tools/patch_framework.py adds to psxrecomp/ (run by tools/recomp_patched.py).

Every .c file here is built into the exe (CMakeLists.txt globs mods/*.c).
